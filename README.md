# SaaSFlow — Modern SaaS Landing Page

A modern, responsive SaaS landing page built with **React, Vite and Tailwind CSS**. SaaSFlow is designed with a clean, premium interface for modern SaaS products, startups and growing teams.

## 🚀 Live Demo

[View Live Demo](https://saas-landing-page-react-steel.vercel.app/).

## 📌 Project Overview

SaaSFlow is a production-style frontend project created to demonstrate modern React development, reusable components, responsive UI design, animations and interactive user experiences.

The project includes a complete SaaS marketing website with a dashboard-style hero section, feature showcase, pricing plans, testimonials, FAQ accordion, CTA section and responsive footer.

## ✨ Features

* Responsive design for desktop, tablet and mobile
* Dark / Light mode
* Modern SaaS dashboard hero section
* Animated statistics counters
* Feature cards with hover effects
* Monthly / Yearly pricing toggle
* Pricing cards with highlighted popular plan
* Customer testimonials section
* Interactive FAQ accordion
* Call-to-action section
* Responsive mobile navigation
* Smooth scrolling
* Back-to-top button

* Reusable React components

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Abdullahyahya12/Saas-Landing-Page-React.git
```

Navigate to the project:

```bash
cd Saas-Landing-Page-React
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run locally through the Vite development server.

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 📱 Responsive Design

The interface is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

The layout adapts using responsive Tailwind CSS utility classes.

## 🌙 Dark / Light Mode

SaaSFlow includes an interactive theme switcher that allows users to switch between dark and light modes.

The selected theme dynamically updates the appearance of the complete interface.

## 🧩 Component Architecture

The application is divided into reusable React components instead of keeping the entire interface inside a single component.

Major sections include:

* Navbar
* Hero
* Stats
* Features
* Pricing
* Testimonials
* FAQ
* CTA
* Footer
* Back to Top

This structure makes the project easier to maintain, test and extend.
